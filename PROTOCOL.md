# Experiment 007: Known probabilities

Authorized budget: US$5 total. Freeze this protocol, source and synthetic cases before inference. No prompt tuning based on results. Model: jev-1.13.0, current stable version checked 2026-09-22.

## Question

How accurately do Jev's probability outputs represent known random-process probabilities? This tests analytic probability fidelity and coherence, not universal classification calibration. The ground truth is a probability distribution, not an observed random outcome. No simulation is necessary. An accurate numerical multiple-choice answer is distinct from a calibrated outcome distribution.

## Design

60 binary cases: fair coins 12, biased coins 6, dice 10, cards 8, sampling 10, uniform integers 6, conditional probability 8. Eight additional multiclass cases cover symmetric and asymmetric distributions. Exact rational answers are generated by enumeration or stated formulas. Coin, dice, card and without-replacement calculations include enumeration. Dataset is a small authored diagnostic suite, not a random or hidden benchmark sample.

Each binary case receives six independent questions against the same scenario: plain outcome Choice (primary); explicitly probability-oriented Choice; plain Choice with option order reversed; event Noul; complementary-event Noul; four-option numerical-probability Choice (knowledge control). The numerical control includes the correct value as one unmarked candidate plus three seeded random distractors. Numeric candidates are confined to that question and never enter shared state. TypeSafe documents that questions are independent. This control measures recognition, not unconstrained arithmetic ability.

Each multiclass case receives plain, explicit and reversed Choice. Outcome options partition the entire sample space. No “unknown” option is added because it is not an outcome of the random experiment. Each scenario makes randomness, independence, replacement and conditioning explicit where relevant. Noul uses the documented yes probability, not Choice's separate concentration-based confidence.

Repeat the first 10 binary cases twice after the full primary run, with identical payloads. Keep repeats separate from the 68-case primary denominator. This small repeated subset estimates output repeatability, not independence or representativeness. No adaptive additions.

## Execution and accounting

One request per case, independent questions batched. Four workers, at most 8.33 starts/second. Up to three transport/rate-limit retries per request. Named immutable primary and repeat runs, request/response traces, shared append-only budget ledger. Reserve worst-case 65,536 input tokens before every attempt, charged at US$0.042/million input tokens; outputs free. Missing usage retains reservation. Retain failed cases in coverage and threshold-success denominators; mean errors necessarily use valid responses and must report coverage. Never substitute zero for a failed prediction. API key read only from environment, never serialized.

## Prespecified scoring

Binary primary: mean absolute probability error (percentage points), RMSE, signed error, maximum absolute error, and counts within 1, 5 and 10 percentage points. Report all five binary outcome forms (plain, explicit, reversed, Noul and 1-complement) separately and by family. Controls at p=0 or 1 are also separated from uncertain cases. Uniform 0.5 is a labeled uninformed baseline, not another model.

Multiclass: total variation distance (half the sum of absolute component errors), maximum component error and raw probability-sum deviations. Independently rounded API probabilities may sum slightly away from 1: preserve raw values, allow K*0.005+1e-6 rounding tolerance, and normalize only for distribution metrics. Record raw sums and component probabilities. Binary primary uses the raw event component; flag sum defects separately.

Coherence: absolute difference between original/reversed Choice event probabilities, absolute Noul event+complement-1, and differences between Choice and Noul. Multiclass ordering uses total variation. Repeats report maximum changes and identical-vector count.

Numeric control: exact selected-option accuracy out of all 60 cases. Do not treat its probability of selecting a numerical answer as the chance of the random event. Across different families, equal-case-weight aggregate scores are descriptive only. Report per-case data so large mistakes and counterexamples remain visible. No claim that this diagnoses the architecture, causal mechanism, all-domain calibration, or training contamination.
